# Julie Voice Studio

Accessible, local-first feminine voice training designed for a user with C4 quadriplegia.

## Privacy

The static website does not upload microphone recordings or contain analytics. Saved recordings and progress use browser storage on the device. GitHub Pages only hosts the application files.

## Android installation

Open the published HTTPS page in Chrome, allow microphone access when asked, then use the in-app **Install on this tablet** button or Chrome’s **Add to Home screen / Install app** option.

## Safety

This is an educational practice tool, not a replacement for a speech pathologist or medical care. Stop for throat pain, worsening hoarseness, unusual breathlessness, dizziness, chest discomfort, severe headache, flushing, sweating, or possible autonomic dysreflexia symptoms.
